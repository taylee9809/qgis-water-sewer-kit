# 함정 — DXF 판독

측량현황도·준공도·설계사 납품 도면(DXF)을 읽을 때 실제로 걸렸던 것들. 11·12·40 스킬이 공통으로 참조한다.
**새 함정을 만나면 여기에 한 줄 추가한다**(회차별 수치는 적지 않는다 — 원리만).

## 인코딩
- **AC1032 DXF 는 `$DWGCODEPAGE=ANSI_949` 로 선언돼 있어도 실제로는 UTF-8 인 경우가 많다.** 선언을 믿고 cp949 로 디코딩하면 한글이 깨진다. ezdxf 기본 읽기로 깨지면 UTF-8 로 다시 시도한다.
- 콘솔 출력은 `PYTHONIOENCODING=utf-8` 또는 `python -X utf8`. (`python -I` 는 환경변수를 무시하니 `-X utf8` 을 쓸 것.)
- 지름 기호 `%%C` 는 정규식 특수문자(`%`)가 아니지만 `%%C300` / `Ø300` / `D300` 이 섞여 온다 — 세 형식을 모두 잡는다.

## 용량
- 측량현황도는 100 MB 를 넘기도 한다. 통째로 `ezdxf.readfile` 하면 MemoryError → **필요한 엔티티만 남긴 경량본**을 먼저 만든다(11 스킬 `01_filter_dxf.py`).
- 대용량 평면 DXF 는 group code 스트리밍 파서로 필요한 레이어만 뽑는 것이 빠르다.

## 종단면도 밴드
- 밴드는 **y 좌표가 고정**이다. 거리·누가거리·지반고·관저고·토피·경사가 등간격으로 쌓인다.
- **수평축은 보통 1 도면단위 = 1 m** — 누가거리 차이와 x 차이가 같은지 먼저 확인하고, 같으면 x 로 밴드 열을 노드에 건다.
- 각 프로파일 왼쪽에 `지반고` `관저고` `토 피` `경 사` **헤더 글자**가 있다 → 프로파일 경계를 나누는 데 쓴다.
- **시트 안에서 DATUM 이 바뀐다.** 표척 숫자 대신 관저고 밴드 값으로 국소 DATUM 을 역산한다.
- 한 행의 마지막 시트는 다른 시트보다 길 수 있다.
- 행 번호는 `floor(y / 행간격)` — **`round` 금지**. 메모는 행 도면 위쪽 띠에 찍혀 round 면 다음 행으로 밀린다.

## 관번호 막대와 라벨
- 관번호 막대와 라벨은 **시트 행별 x 순서로 1:1** 짝짓는다. 계통별로 짝지으면 어긋난다.
- **압송은 평면에서 세분번호(`-00801` …), 종단에서 모관번호 1막대**로 그린다 → 모관번호로 합산한 뒤 대조. 단 **자연유하인데 세분번호면 합산하지 말고 번호 불일치로 지적**한다(관경으로 압송 여부 판정).
- 압송 막대가 여러 시트에 걸치면 순서 짝짓기가 밀린다.
- 막대 위 `L=58.00M` 같은 연장 글자는 막대와 1:1 이라 **작도 오류 교차검증**에 쓴다. 같은 `L=` 형식이 다른 높이(압송 합계 등)에도 있으니 y 범위를 좁혀서 읽는다.

## 라벨 페어링
- 관번호↔`L=`↔`D=` 는 인접쌍으로 묶이지만 **라벨이 겹치는 구역에서 오페어링**이 난다. 의심되면 종단 경사밴드(`L=..m` `S=..‰`)로 교차검증.
- 맨홀 라벨은 심볼에서 10~20 m 떨어져 찍히기도 한다 → 라벨 간 거리가 관 연장과 맞는지로 확인.
- 준공도 라벨은 심볼에서 떨어져 있으므로 **좌표 기준점은 관로 선형 끝점**이 라벨보다 정확하다.

## 레이어와 색
- 신설·기존활용·기존폐쇄는 보통 **레이어 이름과 색(ACI)** 으로 구분한다. 도면마다 규약이 다르니 처음에 레이어 목록·색·엔티티 수를 찍어 규약부터 확정한다(12 스킬 `layer_probe_*`).
- 종평면도는 관번호 라벨이 전부 한 색인 경우가 있어 색으로 신설/기존을 못 가린다 → **평면도에서 판별**.
- 관로 건수가 원본과 안 맞으면 **`기존폐쇄` 포함·제외 여부**부터 의심한다.
- 측량현황도는 경계선·구조물선도 `배수시설물` 같은 시설 레이어에 그려 넣는다 → **레이어만으로 지장물을 거를 수 없다.**

## 지장물 형상 (측량현황도)
- 지장물이 "폴리곤+속성"이 아니라 **선 몇 개 + 떨어진 글자**로 그려져 있다. 변환은 추측 3단계(어느 선이 한 지장물인가 / 폭은 얼마인가 / 어느 글자가 누구 것인가)다 → 검사가 본체.
- ㄷ자(양 벽 + 마구리)를 폴리곤화하면 **두께가 2배**로 잡히는 경우 → `within` 으로 판정해 보정.
- 관벽 2선 + **중심선**까지 3선으로 그린 구간은 polygonize 가 반쪽 둘로 쪼갠다.
- 두 벽선이 끝점을 공유하면 `linemerge` 가 한 줄(머리핀)로 붙인다 → 꺾임각 110° 이상 정점에서 끊는다.
- 굽은 띠의 폭은 둘레·면적으로 역산한다(최소 회전 사각형 폭은 틀린다).
- 실측 1.0 m 가 U1.0 측구인지 D1000 관인지처럼 **도면만으로 결정 불가능한 애매함**이 남는다. 목표는 오류 0 이 아니라 **사람이 확인할 목록 3~5건**.

## 비출력 메모 레이어
- `j_none` 같은 비출력 레이어에 **설계자가 사유 메모**를 남긴다(글자높이가 본문의 10배 이상, 도면 영역 밖).
- "기존관 관저고 확인 필요" 같은 **미확정 표시**가 들어 있다 → 반드시 수거해서 관번호 구간에 매핑.

## 좌표
- 준공도에는 **좌표 오프셋**이 걸려 있는 경우가 많고, 지구(도면 묶음)마다 다르다.
- 기지 맨홀 **3점 이상**으로 산정하고 **0.2 m 이내** 수렴을 확인한 뒤 `asbuilt.offsets` 에 적는다.
- `(base)` 접두 도면은 현황 기반도 — 설계 선형이 일부만 들어 있다.

## makesw `.flo` / `.OUT`
- `.flo` 접속행 꼬리의 기존 GL·IL 은 **토큰 위치(8·9번째, 소수점 있는 것)로** 읽는다. 정규식으로 꼬리 실수를 긁으면 `n=0.01` 을 집는다.
- `.flo` 는 방언이 여럿이다(토큰 구분·방류 예약어 표기). 새 설계사 파일은 먼저 한 줄씩 토큰을 찍어 확인.
- `.OUT` 은 고정 소수 자릿수 서식 — 공백 split 이 숫자끼리 붙은 칸에서 깨진다. 열 위치로 자른다.
- **makesw 서식에는 펌프 용량 항목이 없다** → 압송 첫 줄 주석으로만 남긴다.
- 압송이 또 다른 맨홀펌프장으로 토출되는 **2단 압송**이 있다 → 압송 추적은 다음 노드가 펌프장이면 끊는다.

## 설계사 납품 평면 DXF (13 스킬)
- **속성 블록의 태그 이름이 회차마다 바뀐다**(같은 설계사라도 `관로명2` → `관로명2A`). 태그는 후보 목록으로 받고, 처음엔 스캔(census)으로 확인한다.
- `.flo` 가 **옛 관번호**를 쓰고 평면·종단은 새 번호를 쓰는 회차가 있다 → 관저고가 같은 짝으로 별칭 후보를 찾고, 어느 쪽이 도면 번호인지는 종단 DXF 글자로 정한 뒤 사람이 적용한다.
- **같은 이름의 속성맨홀이 두 번** 들어 있는 경우가 있다 → 레코드를 만들 때 중복을 따로 보고한다(조용히 덮어쓰지 않는다).
- 기존망 접속 노드는 **다른 원점(좌표계 오프셋)**의 준공 자료와 이어진다 → 접속 거리 허용차를 두고, 넘으면 연결하지 말고 보고한다.
- 속성맨홀이 없는 **경량 평면**은 폴리라인 + 관로명 글자로 레코드를 만든다. 펌프장별로 한 줄로 그린 압송은 `.flo` 의 세분구간을 접어 연장을 맞춘다.
- DXF 인코딩은 **버전으로** 판단한다(AC1021 이상 = UTF-8, 선언된 코드페이지는 믿지 않는다).
