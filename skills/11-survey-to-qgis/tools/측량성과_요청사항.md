# 측량성과(DXF) 납품 요청사항 — 지장물 부분

> 측량 요청 공문에 붙일 문구 틀. 이 세 가지만 지켜지면 측량도를 받아서
> **그날 바로** QGIS 지장물 레이어로 올릴 수 있고, 회차마다 생기는
> 규격 오류 확인 작업이 사실상 없어진다.
> `〔 〕` 안은 우리 회차 숫자(03·04·05 결과)로 바꿔 넣는다.

---

## 1. 지장물 도형에 속성(ATTRIB)을 부여해 주십시오 ★ 가장 중요

지장물(횡배수관·측구·BOX·암거)을 **블록으로 작도하고 아래 속성을 부여**해 주시기 바랍니다.

| 태그 | 내용 | 예 |
|---|---|---|
| 종류 | 횡배수관 / U형측구 / BOX / 암거 / 우수관 / 상수관 | `횡배수관` |
| 관경 | 원형관은 호칭경(mm) | `600` |
| 규격 | 사각은 내공 폭×깊이(m) | `0.30X0.30` |
| 관저고 | 내공 바닥고(EL.m) — 조사된 경우 | `29.58` |
| 비고 | 현행/매립, 관측불가 등 | `매립` |

- 참고 형식: 같은 사업 설계사 평면도의 `기타데이터` 블록이 동일한 방식입니다
  (태그 예: 관로명·관종·관경·BOX·관저고·지반고·포장·포장폭·도로폭·비고).
- 이 속성이 있으면 저희 쪽에서 **도형과 속성을 그대로 읽어** 레이어로 만듭니다.
  속성이 없으면 선과 텍스트의 위치 관계로 규격을 **추정**해야 하고, 거기서 오류가 발생합니다.

## 2. 관로는 평행 2선으로 끝단까지 폐합해 주십시오

- 현재 한 도면 안에 네 가지 작도 방식이 섞여 있습니다 —
  ① 평행 2선(관벽), ② **ㄷ자(두 변 + 막힌 끝 한 변)**, ③ 단선 하나, ④ 닫힌 폴리라인.
- ②와 ③은 **관의 폭을 도면에서 읽을 수 없습니다.** 특히 ②는 저희 자동 변환에서
  두께가 2배인 ㄷ자 폴리곤으로 만들어집니다(〔이번 회차 N건〕 확인).
- 요청: **관벽 평행 2선 + 양 끝단 폐합**(①)으로 통일. 폐합선 끝점은 관벽선 끝점에
  정확히 일치시켜 주십시오(현재 수 mm 어긋나 있어 자동 폐합이 실패합니다).

## 3. 규격 라벨은 해당 선에 밀착시키고 표기를 통일해 주십시오

- **밀착**: 규격 텍스트를 해당 지장물 선에서 **0.3 m 이내**에 배치해 주십시오.
  현재는 수 m 떨어져 있어, 인접한 다른 지장물이 그 라벨을 가져가는 오류가 생깁니다
  (예: 도로 횡단 D600 관이 4.4 m 옆 측구의 `U형측구03x03` 라벨을 받아감).
- **표기 통일**: 현재 아래가 혼용되고 있습니다.

  | 현재 혼용 | 통일 요청 |
  |---|---|
  | `D600` / `%%C600` | **`D600`** (원형관, 호칭경 mm) |
  | `U0.6X0.6` / `U형측구06x06` / `U형측구0.6x0.6` | **`U0.6X0.6`** (소수점 명기) |
  | `Box 2@3.0X2.0` / `박스` / 접두어 없는 `4.5X1.0` | **`BOX 3.0X2.0`**, 2연은 `BOX 2@3.0X2.0` |
  | `H1.5` 단독 | 폭 없이 깊이만 쓰지 말 것 |

  ※ 소수점 없는 2자리(`06x06`)는 0.6 m인지 6 m인지 도면만으로는 구분이 안 됩니다.

## 참고 — 측량 범위 밖이라 저희가 다른 자료로 보완하는 항목

요청이 아니라 공유 사항입니다. 아래는 측량현황도에 없어도 정상입니다.

- **지중 상수관**: 지자체 상수관망 GIS 로 대조합니다
  (한 회차에서 종단에 나온 상수관 25건 전부 상수관망 자료와 거리 0.0 m 로 확인).
- **지중 소구경관(D50~D150)**: 지상에서 보이지 않아 측량에 안 잡힙니다.
- 다만 **설계사 종단에는 있는데 측량도에 없는 횡배수관**이 나오면 추가 조사가 필요한 지점일 수 있어
  별도로 전달드리겠습니다(06_check_profile 의 '없음' 중 상수관이 아닌 것).
