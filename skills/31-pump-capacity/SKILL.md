## 0. 시작 전 사용자와 합의 (매번 묻는다)

1. **기존 / 신설 구분** — 기존(준공) 펌프장은 **준공 스펙 고정, 유량만 바꿔 검토**. 신설만 산정한다. 이 구분은 매번 요구된다.
   기존 = `plan_pump` 의 구분값이 `values.pump_existing`(기본 `기존`)으로 시작 ∪ `asbuilt_pump` 레이어 ∪ `--specs` ∪ `--existing`.
2. **유량** — 펌프장까지 누가한 **계획시간최대오수량**(KDS 61 45 00 표 1.1.1: 분류식 중계·소규모 펌프장 계획하수량).
   기존 검토의 비교 시나리오(당초/변경, 실측 보정 등)를 어떻게 둘지.
3. **후단 매설배관 관경** — 원 계산서는 `80A`, 설계 압송관은 `D75` 처럼 다를 수 있다. 어느 쪽으로 계산할지 정하고 보고에 적는다(5절 첫 함정).
4. **자체 가정 값**(기준 아님) — 여유양정 1.5 m · 전효율 23 % · 동력여유 1.15 · HWL = 유입관저 − 0.05 · 유효수심 0.5 · 사수심 0.55 · 최소 0.10 ㎥/min · 기동 허용 10 회/h · 1+1 대.
   바꾸면 `design.pump.*` 에 적고 근거를 `결정기록.md` 에.
5. **기존 판정 기준** — 정격점(명판 토출량·양정)으로 볼지, 운전점(제조사 곡선 ∩ 시스템곡선)으로 볼지. 우리는 **정격점**으로 정했고 운전점은 참고로 냈다.
6. 망에 **유입관이 없는 펌프장**(처리장 통과유량 이송 등)의 유입관저고 가정값.

## 3. 산식 (원 계산서 방식)

**망·펌프장 (p1)**
- 펌프장 = 유출관 D ≤ `pressure_max_d_mm` 이고 (유입관이 없거나 그보다 큰 자연유하 유입관이 있는) 노드 ∪ 지정 ∪ 기존.
  압송만 받아 다시 압송하는 **중계 펌프장**은 이 규칙에 안 걸린다 → 기존 목록·`--pump` 로 넣는다.
- 압송관 추적: 유출관에서 하류로, **다음 펌프장이거나 자연유하 유입이 합류하는 노드에서 끊는다**(2단 압송에서 연장 부풀림 방지).
  압송최상단 BOP = 그 구간 관저고 최대값, 압송연장 = 구간 연장 합, 토출대상 = 끝 노드.
- 유량 Q = 펌프장 노드 누가(.flo `Q=` ㎥/s 는 노드 자체유량 → 위상순 누가). 레이어 망은 **펌프 유출관의 누가유량**을 그대로 쓴다.
- 유입관저고 = 유입관 하류관저 최솟값. 없으면 `--inlet`(가정으로 표시) → `plan_pump.in_invert`.

**신설 (p2)**
```
HWL = 유입관저 − 0.05      LWL = HWL − 0.5      저면 = LWL − 0.55
q   = MAX(ROUNDUP(Q[㎥/min] / 가동대수, 2), 0.10)
토출구경 = 146·√(q / v) 가 v = 1.5~3.0 m/s 에 드는 최소 표준구경 (없으면 50A 이상 최소)
v   = q·4 / π / (D/1000)² / 60                                  [m/s]
hf  = Σ_펌프측 K·v²/2g  +  직관 f·L/D·v²/2g  +  토출구 K·vb²/2g  +  편락관 K·(vb − v)²/2g
       (v = 토출구경 기준, vb = 후단 매설배관 = 압송관경 기준)
hl  = 10.666 · C^-1.85 · (D/1000)^-4.87 · (q/60)^1.85 · L         (Hazen-Williams, C = 100, D = 후단관경)
ha  = 압송최상단 BOP − LWL
H   = ROUND(ha + hf + hl + 1.5, 0),   hv = H − (ha + hf + hl)    ← hv 는 "잔류속도수두" 칸이지만 실제론 정수 맞춤 여유
P   = 0.163 · q · H / 0.23 × 1.15  →  표준전동기표
V   = π/4 · 1.5² · 0.5            최소운전 V/q,  최대기동 60/(4V/q) = 15q/V  (유입 = q/2 일 때 최대)
시간최대 유입 Q 일 때:  운전 V/(q−Q), 정지 V/Q, 기동 60/(운전+정지)
직렬 순간유입 = Σ 상류 펌프 q + (자기 Q − Σ 상류 Q)       직렬 여유 = q / 순간유입 (1 미만이면 상류 펌프 1회 운전 동안 수위 상승)
압송관경 대안 = alt_force_main_dia_mm 각각으로 hl·H·kW·유속
```

**기존 (p3)** — 설치 q·H·kW 는 명판 그대로.
```
소요 q = MAX(ROUNDUP(Q/가동대수,2), 0.10)   용량 OK ⟺ 소요 q ≤ 설치 q      사용률 = Q / 설치 q,  여유배 = 설치 q / Q
양정: q = MAX(소요, 설치) 로 ha + hf + hl (= 소요양정) ≤ 설치양정   (여유 포함 반올림값도 같이 낸다)
      BOP·압송연장은 준공값(제원) 우선, 없으면 망 추적값. LWL 은 준공값, 없으면 유입관저 규칙
동력: P(q, 소요전양정) → 표준전동기 ≤ 설치동력
압송유속 = 설치 q 의 후단관 유속 → 0.6~3.0. 0.6 미달은 용량 문제가 아니라 퇴적·황화수소 대책 문제
기동: 15q/V ≤ 10 회/h, 시간최대 유입 시 운전/정지/기동
저류(참고): 1시간 유입 vs V + q·60  — 1차 판정은 언제나 「설치 q ≥ 시간최대」
자연유하관(--pipes): Manning 부분만관 — 사용률 = q/Q만관, 실유속, 수심비, 판정 GOOD / LESS0.6 / OVER3.0 / 만관초과
```

**운전점 (p4)** — 시스템곡선 h(q) = (BOP − 수위) + hf(q) + hl(q), 펌프곡선과 교점. 수위 LWL(실양정 최대 = 토출 최소, 판정용)과 HWL.
체절양정 < 실양정이면 토출 불가, 곡선 끝까지 교점이 없으면 런아웃.

## 4. 합격 기준 (결과를 믿기 전에)

| 항목 | 기준 |
|---|---|
| 원 계산서 재현(p0) | 집계 q·ha·hf·hl·hv·H **차 < 0.005** — 시트별 변형은 `--variant` 로 재현하고 그 목록을 보고 |
| 망 | `--check-flo` ERROR 0 · 순환 없음 · **펌프장 수 = 도면(평면·종단)의 펌프장 수** |
| 유입관저 가정 | 「유입관저고를 정할 수 없는」 목록 0, 또는 가정값과 근거를 보고에 명시 |
| 신설 | 압송유속 0.6~3.0(미달이면 관경 대안표와 사유) · 최대기동 ≤ 10 회/h · q ≥ 0.3 이면 제조사 곡선으로 동력 재확인 표시 |
| 계산서(`--template`) | 엑셀 재계산값 ↔ 엔진 **최대차 0**(스크립트가 찍는다). 불일치면 양식 식 변형부터 의심 |

| 쓰기 | `--write` 후 갱신 행수 = 대상 수, 레이어에 없는 펌프장 0, 백업 경로 보고 |

## 5. 함정

- ★ **후단 매설배관 80A vs D75** — hl 이 D^−4.87 이라 **약 1.37 배** 차이(75 → 80 이면 hl × 0.73). 원 계산서는 80A, 설계 압송관은 D75 인 경우가 있다.
  어느 쪽을 썼는지 보고서에 반드시 적는다. 비교가 필요하면 `--set alt_force_main_dia_mm=[75,80]`.
- **압송관 내경** — 호칭 75 내충격수도관은 외경 89 / 내경 약 77. 같은 관을 기계도면은 `D80`(배관호칭), 토목 종단은 `D75` 로 적는다(오독 아님).
  PE SDR11 내경 61 로 잡으면 손실이 약 3배로 과대.
- **기존 = 준공 스펙 고정** — 기존 펌프장을 산정식으로 다시 고르지 않는다. 그리고 **납품 명판(기자재 준공도서)이 설계 기기목록과 다를 수 있다**
  (예: 기기목록 6 mH → 명판 13 mH). 명판이 있으면 명판이 우선, 출처를 남긴다.
- **기기목록에는 펌프장 이름이 없다** — `맨홀펌프 #1~#n`, `P-101~` 뿐이다. 편철 순서로 짝지었다면 「가정」이라고 쓴다(p5 `--map-note`). 단정 금지.
- **제원표에 실양정·전양정이 없다** — 실양정은 (도달점 관저 또는 압송관 정점) − LWL 로 직접 낸다. 제원표 `유출관저고`를 BOP 로 쓰되 종단 정점이 더 높으면 종단 값.
- **같은 압송연장이 도면마다 다르다** — 기계 제원표·토목 종단·기계 계산서가 3.0 / 6.4 / 33 m 처럼 갈린 적이 있다. 종단(실측 구간)을 쓰고 근거를 적는다.
- **맨홀깊이 ≠ 지반고 − 저면고** — 도면 맨홀깊이는 구체 상단(G.L − 상부여유) 기준이다. 수리에는 영향 없고 물량에만.
- **원 계산서는 시트마다 식이 다를 수 있다** — 용량 ROUNDUP 자리수(2 vs 1), 여유양정 1.6 + 올림, 고정 용량, 다른 행 연장 참조(오기). 재현(p0)부터 하고 고칠 건 따로 제안.
- **원 계산서 양식 결함** — 옥외관로 hl 식에 관경 0.08 하드코딩(→ 후단관경 칸 참조로), 표준전동기표에 7.5~11 kW 행 누락(VLOOKUP 이 8 kW → 7.5 로 과소). p6 `patches` 가 고친다.
- **전효율 23 % 는 0.1~0.2 ㎥/min 급 관행값** — 0.4 ㎥/min 이상이면 실제 효율이 더 높다. 제조사 곡선(p4)으로 동력 재확인하라고 보고에 적는다.
- **장거리 소구경 압송은 hl 이 전양정을 지배한다** — D80 943 m 에서 hl 52 m → 89 mH. 관경 대안표(p2)로 유속 0.6 이상 유지 범위의 최대 관경을 찾고, 그래도 크면 노선·중계 검토(32).
- **소유량 펌프장의 압송유속 0.6 미달**은 q 를 키워도(최소 0.10) 관경을 줄여도 한계가 있다 — 「퇴적·황화수소 대책」으로 처리하고 사유를 적는다.
- **2단 압송** — 압송이 다른 펌프장으로 토출되면 추적을 끊는다. 안 끊으면 연장·BOP 가 부풀어난다.
- **망에 유입관이 없는 펌프장**(처리장 통과유량 이송 등) — 유입관저를 망에서 못 낸다. `--inlet` 가정값 + 근거(예: 연결되는 준공 맨홀 하류관저).
- **운전점은 유입량과 무관하다** — 유입이 바뀌면 가동률·기동횟수만 바뀐다. 정격점은 여유를 얹은 선정 목표점이라 운전점은 보통 그 오른쪽(토출 더 큼).
- **최대기동횟수 15q/V 는 펌프·흡수정만으로 정해진다** — 당초/변경 시나리오에서 값이 같아야 한다. 유입별 기동횟수는 「시간최대 시 기동」 열로 따로 낸다.
- **저류식 판정(1시간 유입 < V + q·60)의 결함** — q < 시간최대도 통과시켜 KDS 61 45 00 표 1.1.1(계획하수량 = 시간최대)과 어긋나고,
  평상시 수위를 모르면 V 전량을 저류로 못 쓴다. 요청받으면 참고 열로만 내고 1차 판정은 「설치 q ≥ 시간최대」로 둔다.
- **파이썬 `round` ≠ 엑셀 `ROUND`** — 파이썬은 .5 를 짝수로. 킷은 `xround`(0.5 올림)로 엑셀과 맞춘다.
- **GPKG 속성만 UPDATE 해도 실패** — GDAL 이 만든 rtree 트리거가 `ST_IsEmpty` 등을 부른다. 킷 `pumplib.gpkg_connect()` 가 그 함수를 등록한다.
  QGIS 가 그 GPKG 를 열고 있으면 저장 충돌이 나므로 레이어를 닫거나 QGIS 쪽에서 다시 읽는다.
- **Excel COM** — `Sheet.Copy(After=…)` 키워드가 무시돼 새 통합문서로 복사된다 → 위치 인자 `Copy(None, 시트)`. 다른 시트 참조식은 그 시트가 생긴 **뒤**에 넣어야 `#REF!` 가 안 남는다.
  숨김 시트는 Move 가 안 된다. 양식 원본은 열지 말고 사본을 연다(p6 가 그렇게 한다).
- **DXF 인코딩** — `$DWGCODEPAGE = ANSI_949` 라도 AC1021 이상은 UTF-8 이다(ezdxf 가 알아서 읽는다). 한글이 깨지면 `pitfalls-dxf.md`.

## 6. 사례 (교훈만)

- **전체망 23개소(신설 17 · 기존 6)** — 엔진값과 원 계산서 양식 복제본의 엑셀 재계산값이 17개소 전 항목 일치(킷 재실행으로도 차 0).
  장거리 D80 압송 5개소가 25~89 mH · 11~37 kW 로 나와 관경 대안표를 붙였고, D100 이면 13~55 mH · 5.5~22 kW, D150 은 유속 0.4~0.49 로 미달.
  → 관경 변경은 사람이 결정했고(D100), 가장 긴 1개소는 D100 에서도 55 mH 라 노선·중계 검토로 넘겼다. 설계사 수리계산 출력에는 펌프 양정·동력이 없었다.
- **기존 6개소 검토** — 설계 기기목록 양정(6 mH)과 실양정(8.98 m)이 안 맞는 쟁점이 납품 명판(13 mH)을 찾아 해소됐다.
  명판이 기기목록과 다른 개소가 더 있었다(8 → 6 mH). 전 개소 교체 불필요. 기존 압송관 유속은 6개소 중 5개소가 0.38~0.49 m/s 로
  0.6 미달 — 용량이 아니라 유지관리(퇴적·황화수소) 대책으로 정리.
- **원 계산서 재현** — 4개 시트 중 3개가 식 변형(용량 자리수 1, 여유 1.6 올림, 고정 0.1 + 다른 행 연장 참조). 변형을 재현해 「같은 식」을 확인한 뒤에 금회 값을 넣었다.
- **운전점** — 6개소 모두 운전점 토출(0.12~0.22)이 정격(0.10~0.20)보다 컸다. 판정 기준은 정격점으로 하기로 결정, 운전점 표는 참고로.
- **기계 준공도 판독(p5)** — 서식 2종(기기번호·기기명·사양·동력·가동/예비/계 열 / 사양 2줄·수량 `2(1)`)에서 펌프 행을 모두 읽었고,
  제원표 4개소는 손으로 옮긴 값과 전 항목 일치. 송풍기(`㎜Aq`)·교반기 행은 펌프가 아니라 걸러진다.
