## 1. 제약조건 수집 (C1)

- **지장물 교차** — 노선 레이어의 종단지장물 필드(`fields.plan_pipe.obstacles`), 종단↔QGIS 대조 결과.
- **암거·박스** — 제원(내공 W×H), **도면하단 EL**, **상단 EL**, 지반고.
  → **복토 = 지반고 − 상단** 을 먼저 재서 상부 통과 가부를 판정한다(복토 1 m 미만이면 불가).
- **현장사진**(로드뷰)으로 구조물 성격 확인 — 도로 하부 횡단암거인지, 개수로인지.
- 하월 시 관저 상한 = `도면하단 − 관경 − 여유`.

## 2. 수용 가능 맨홀 전수 탐색 (C2) — `scripts\gravity_scan.py`

각 기존 맨홀에 대해

```
필요 시작관저 = 유출관저 + (최소경사 × 직선거리)
가능 ⟺ 필요 시작관저 ≤ 출발 관저
```

```
python -X utf8 "<킷>\skills\32-route-optimize\scripts\gravity_scan.py" --district <지구> ^
       --start "펌프장 노드" <관번호> dn  --start "상류 단차 제거 노드" <상류 관번호> dn  [--min-slope 7] [--top 14]
```
- 출발 노드 = 계획 노선 관번호의 상류(`up`)/하류(`dn`) 끝점과 그 관저.
- ★ **가까운 순으로 정렬**해서 볼 것(스크립트가 그렇게 찍는다). 여유 순으로 정렬하면 멀고 깊은 답이 1등으로 올라온다.
- ★ **출발점을 2가지로 돌린다** — (a) 현재 펌프장 노드, (b) 상류 단차를 제거한 노드.
  (a)에서 전부 불가여도 (b)에서 성립하는 경우가 많다. `--start` 를 두 번 주면 한 번에 나온다.
- 최소경사는 `design.min_slope_permil`(KDS 61 40 00 기준 **5‰**). 여유를 보려면 `--min-slope 7` 로도 돌려본다.

## 3. 종단 성립성 (C3) — `scripts\profile_check.py`

```
python -X utf8 "<킷>\skills\32-route-optimize\scripts\profile_check.py" ^
       --from-pipe <출발 관번호> dn --to-mh <도착 맨홀> --district <지구> ^
       --plan 5.0 --plan "7.6:7.6‰ 여유안" --check <측점m> "박스 내공저면 <EL>"
```
- 좌표를 직접 줄 수도 있다: `--from X Y --to X Y --il-b <도착 유출관저>`.
- 출발~도착 직선을 DEM(설정 `dem` 순서, 실측 1 m 우선)으로 10 m 간격(`--step`) 샘플링 → **토피** 산출.
- 합격: 토피 `design.min_cover_m`(1.0 m) 이상(스크립트가 경사안마다 판정 한 줄), 과도한 심굴착(4 m 이상)이 긴 구간에 걸리지 않을 것.
- 제약 지점(암거 등)은 `--check 측점 설명` 으로 관저·관상단을 따로 찍어 **구조물과의 상하 관계**를 확인.
- 상류 캐스케이드: 시작관저를 올리면 상류 구간의 **지장물 이격이 줄어든다** → 재확인.

펌프장 삭제는 **공사비보다 운영비·유지관리**에서 값이 나온다. 그 점을 비교표에 적을 것.
최소경사·토피 기준을 과업 기준으로 바꿨으면(설정 `design` 또는 인자) 비교표에 기준값과 자체 가정을 구분해 적는다.

## 사례

한 지구의 맨홀펌프장 + 압송 구간 제거 검토.
- 펌프장 노드(IL 58.34) 출발 → 인근 맨홀 전부 불가(가장 가까운 가능 맨홀이 271 m)
- 상류 단차 0.96 m 제거 + 박스 측벽 통과 전제 → **기존 맨홀 A**(유출관저 58.64) **170 m / 5.82‰ 성립**
- 여유 두려면 시작관저 0.30 m 상향(7.6‰), 토피 2.3~4.5 m
- 교훈: 출발점 하나만 돌렸으면 "불가"로 끝났을 검토다. 박스 지점(측점 3.2 m)은 `--check` 로 관상단을 따로 찍어 측벽 통과 가부를 봤다.
